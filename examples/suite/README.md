# 기존 AST 엔진용 합성 문제 24개

현재 기본 토큰 엔진과 네이티브 프로그램에서 사용하는 **40문제 세트는 [토큰 합성 문제 안내](../token/README.md)**를 참고하세요. 기존 24문제에 문자열·슬라이스·map·반복문 문제를 각 4개씩 추가한 구성입니다.

이 디렉터리는 프로그램에서 AST 엔진을 선택해 실행하는 기존 AST 엔진용 수작업 합성 문제 24개를 담습니다. 산술·비교·불리언·조건문·다단계 계산·지역 변수 관련 의미를 각 4문제씩 포함합니다. 일반적인 코드 이해 정확도를 대표하는 표준 벤치마크는 아닙니다.

- `specs/`: 자연어 의도, 함수 시그니처, 상수와 공개 테스트
- `heldout/`: 제출 후보 고정 뒤에만 읽는 별도 평가 입력
- `references.json`: 검증용 참조 함수 본문과 문제 경로. 합성 입력으로 전달하지 않음
- `../benchmark-expanded.json`: 같은 의미를 다루는 후보 선택 문제 24개
- `../compare.json`: 가짜 모델 × 문제 24개 × 전략 3개의 실행 설정
- `../compare-live.json`: 사용자가 직접 실행하는 Jev·로컬 Decider 비교 설정

선택 후보는 중립적 ID를 사용하고 정답 위치를 분산했습니다. 오답은 연산자, 비교 방향, 분기, 초기값·대입 결과를 바꾼 코드입니다. 덧셈·미만·초과 문제에는 동등한 정답 후보가 두 개씩 있습니다. 정수 문제는 공개 입력 4개와 최종 평가 입력 8개를 사용합니다. 유한한 불리언 입력 공간은 중복 없이 공개/평가 집합으로 반씩 나눕니다.

입력은 작은 정수와 0이 아닌 나눗셈 분모로 제한합니다. `int` 오버플로·최소 정수의 절댓값·임의의 큰 입력에 대한 정당성을 증명하지 않습니다. 테스트 파일은 저장소에 공개돼 있으므로 별도의 연구용 비공개 평가 세트로 간주해서는 안 됩니다.

`scope-*` 함수도 지역 변수를 사용하지 않고 동등하게 합성할 수 있습니다. 이런 프로그램은 정답으로 인정합니다. 변수 선언·변경·스코프 자체의 지원 근거는 합성기와 검증기의 결정적 통합 테스트이며, 데이터셋 통과율과 구분합니다.

가짜 모델은 코드 의미를 이해하지 않고 고정된 순서로 점수를 매깁니다. 가짜 모델의 실패율·성공률은 실험 도구가 상태를 올바르게 수집하는지 확인하는 용도입니다. 실제 비교 시에는 문제·문법·예산·모델 revision·반복·순서를 함께 기록하고 비용과 지연을 성공 사례에 대해서만 골라 보고하지 않습니다.
